## 📌 О проекте

**MicroLog** — небольшая библиотека логирования для Python, построенная вокруг одной идеи: **делать свою работу без лишней сложности**.

Она предоставляет базовые уровни логирования, вывод в консоль, запись в файл, возможность включать и отключать логирование, а также настраиваемый путь к лог-файлу, сохраняя реализацию компактной и понятной.

## 🧩 Возможности

- **Три уровня логирования:** `INFO`, `WARNING`, `ERROR`
- **Вывод в консоль** с ANSI-цветами уровней
- **Запись в файл** `.log` или текстовый файл
- **Записи с временной меткой**
- **Визуальные маркеры уровней** с помощью `🟢`, `🟡` и `🔴`
- **Включение / отключение логирования** во время работы
- **Настраиваемый путь к лог-файлу** через `Path`
- **Автоматические заголовки лог-файла** для новых сессий логирования
- **Минимум зависимостей** — библиотека использует стандартную библиотеку Python

## 🔮 Философия

MicroLog намеренно остаётся маленьким.

Проект не пытается заменить функционально насыщенные фреймворки логирования. Вместо этого он сосредоточен на ограниченном наборе полезных возможностей и сохраняет архитектуру простой, читаемой и предсказуемой.

> **Маленький. Простой. Достаточно быстрый. Предсказуемый.**

## 🕹️ Использование

Импортируйте `Logger` из пакета:

```python
from microlog import Logger

log = Logger()

log.info("Good!")
log.warning("Look out!")
log.error("Error!!!")
```

### ▶️ Включение и отключение логирования

```python
log.disable()
log.info("Это сообщение не будет записано")

log.enable()
log.info("Логирование снова включено")
```

### 🛠️ Изменение файла логирования

```python
log.path = "./microlog.log"
log.info("Запись в пользовательский лог-файл")
```

`path` принимает путь к файловой системе и внутри хранится как объект `pathlib.Path`.

## 📤 Вывод

### 🖥️ Консоль

Консольный форматтер выделяет уровень логирования цветом для быстрого визуального распознавания:

```text
[2026-09-11 23:29:27.529479] [INFO] - Good!
[2026-09-11 23:29:27.529547] [WARNING] - Look out!
[2026-09-11 23:29:27.529563] [ERROR] - Error!!!
```

`INFO`, `WARNING` и `ERROR` отображаются разными ANSI-цветами.

### 📄 Лог-файл

Файловый вывод сохраняет читаемый текстовый формат и добавляет визуальный символ для каждого уровня:

```text
___________________________[ 2026-09-12 ]___________________________
<< [2026-09-12 01:41:24.973005] [🟢] [INFO] - Good!
<< [2026-09-12 01:41:24.973137] [🟡] [WARNING] - Look out!
<< [2026-09-12 01:41:24.973173] [🔴] [ERROR] - Error!!!
```

Заголовок записывается при начале новой сессии логирования для текущего пути к лог-файлу.

## 📊 Архитектура

MicroLog намеренно использует небольшую архитектуру:

```text
Logger
  │
  └── Formatter
        ├── console()
        ├── file()
        └── headline()
```

### 📝 `Logger`

Отвечает за жизненный цикл логирования и публичный API:

- `info()`
- `warning()`
- `error()`
- `enable()`
- `disable()`
- `path`

Приватный метод `_log()` содержит общую реализацию, используемую всеми уровнями логирования.

### 🖌️ `Formatter`

Отвечает за преобразование собранных данных лога в отформатированные строки для вывода в консоль и файл.

Библиотека намеренно избегает более крупной иерархии обработчиков, фабрик и других абстракций, чтобы сохранить ядро небольшим.
